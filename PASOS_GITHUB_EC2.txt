# COMANDOS PARA SUBIR A GITHUB Y DESPLEGAR

## 1. SUBIR A GITHUB (Ejecutar en tu PC)

# Inicializar git
git init
git add .
git commit -m "API Red Social Lista"

# Crear repo en GitHub primero, luego:
git branch -M main
git remote add origin https://github.com/TU_USUARIO/nombre-repo.git
git push -u origin main

## 2. CREAR EC2

- Ubuntu 22.04 LTS
- t2.micro (Free Tier)
- Security Group: Puertos 22, 80, 443
- Descargar clave .pem

## 3. CONECTAR A EC2

ssh -i tu-clave.pem ubuntu@TU_IP_PUBLICA

## 4. DESPLEGAR (Una sola línea)

# Opción A: Clonar y ejecutar script
git clone https://github.com/TU_USUARIO/nombre-repo.git ~/red-social-api
cd ~/red-social-api
chmod +x deploy_ec2.sh
./deploy_ec2.sh

# Opción B: Todo en uno (edita la URL)
bash <(curl -s https://raw.githubusercontent.com/TU_USUARIO/nombre-repo/main/deploy_ec2.sh)

## 5. LISTO!

API: http://TU_IP_EC2
Docs: http://TU_IP_EC2/docs

## ACTUALIZAR DESPUÉS

cd ~/red-social-api
git pull
sudo systemctl restart red-social-api

## VER LOGS

sudo journalctl -u red-social-api -f

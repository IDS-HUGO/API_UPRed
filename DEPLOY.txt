# 🚀 DESPLIEGUE RÁPIDO EN EC2

## Paso 1: Crear instancia EC2
1. Inicia sesión en AWS Console
2. EC2 → Launch Instance
3. Selecciona: **Ubuntu 22.04 LTS**
4. Tipo: `t2.micro` o superior
5. Security Group - Abre puertos:
   - **22** (SSH)
   - **80** (HTTP)
   - **443** (HTTPS opcional)
6. Crea/selecciona Key Pair (.pem)
7. Launch

## Paso 2: Conectar a EC2
```bash
chmod 400 tu-clave.pem
ssh -i tu-clave.pem ubuntu@TU-IP-PUBLICA
```

## Paso 3: Subir código a GitHub

## Paso 4: Desplegar (EN EC2)
```bash
# Edita el script primero
wget https://raw.githubusercontent.com/TU_USUARIO/TU_REPO/main/deploy_ec2.sh
nano deploy_ec2.sh  # Cambia TU_REPO_GITHUB_AQUI por tu repo
chmod +x deploy_ec2.sh
./deploy_ec2.sh
```

## Paso 5: Listo 🎉
Tu API estará en: `http://TU_IP_EC2/docs`
